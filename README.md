# Каменск-Уральский: доступность социальной инфраструктуры в сжимающемся городе

ГИС-анализ пешеходной доступности школ, детских садов и поликлиник в Каменске-Уральском
(Свердловская область, ~160 тыс. человек) и оценка того, какие объекты можно
перепрофилировать без потери доступности для жителей.

**Главный вопрос:** сколько объектов социальной инфраструктуры можно закрыть или
перепрофилировать, не ухудшив 15-минутную пешеходную доступность, и какие территории
при этом высвобождаются?

**Главный результат:** _(заполнить после расчёта — одна цифра, например: «12 объектов
из 87 избыточны по покрытию; их закрытие не снижает доступность ни в одной жилой ячейке,
высвобождается ~N тыс. м²»)_

---

## Зачем это

Город теряет население с 1989 года (207 780 → 160 312 человек по Росстату), но сеть
социальных объектов осталась рассчитанной на большее число жителей. Муниципалитеты
обычно не умеют считать, какие объекты действительно избыточны, а какие держат
доступность в отдалённых посёлках. Проект предлагает воспроизводимую методику такого
расчёта.

## Данные

| Данные | Источник | Формат |
|---|---|---|
| Улично-дорожная сеть, здания, POI | OpenStreetMap (Geofabrik, УрФО) | PBF |
| Граница городского округа | OSM relation 1298867 | полигон |
| Школы, детские сады (адреса) | obr-ku.ru | HTML |
| Медицинские организации | miacso.ru | PDF |
| Население, ввод жилья | ЕМИСС / БД ПМО | XLSX |
| Застроенная территория | GHSL (JRC) | GeoTIFF |

Подробно — в [docs/DATA.md](docs/DATA.md).

## Метод (кратко)

1. Пешеходный граф города по OSM (`osmnx`).
2. Изохроны 10 / 15 / 20 минут от каждого объекта.
3. Агрегация на гексагональную сетку H3.
4. Индекс доступности: время до ближайшего объекта каждого типа.
5. Поиск объектов, полностью дублируемых соседними (greedy set cover).
6. Сценарий: какие объекты закрываются, что происходит с доступностью.

## Ограничения

- Население по кварталам не публикуется — используется прокси по жилым зданиям.
- POI в OSM неполные — сверяются с официальными перечнями.
- Пешеходная сеть OSM неровная: тротуары и переходы покрыты неравномерно.
- Вместимость объектов в открытых данных отсутствует — сценарий строится на покрытии,
  а не на загрузке мест.
